# andreisarte.com

Official repository for **andreisarte.com**, the public web domain of Andrei Sarte.

## Purpose

The site serves as a public interface for Andrei's projects, systems, experiments, and evolving work around AISE.

## Current Structure

- `index.html` — primary domain interface
- `style.css` — visual system and layout
- `script.js` — interactive behavior and Jarvis SE console
- `about.html` — reserved page for future expansion
- `projects.html` — reserved page for future expansion
- `_config.yml` — site configuration

## AISE

AISE is an evolving framework and identity used to organize systems, projects, and AI-assisted experimentation. The website currently exposes only a limited public-facing layer of that work.

## Status

Early development. Structure, content, projects, and public documentation will expand over time.
